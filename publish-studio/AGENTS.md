# publish-studio

Creator dashboard for Directwerk — **Write desk** (articles) and **Podcast desk** (episodes).

See [`../docs/publish-studio-implementation.md`](../docs/publish-studio-implementation.md) and
[`../docs/publication-desks-model.md`](../docs/publication-desks-model.md).

```sh
pnpm install
pnpm dev   # http://localhost:3002
```

Set `NEXT_PUBLIC_API_URL` to the Directwerk API (e.g. `http://localhost:8080`).
